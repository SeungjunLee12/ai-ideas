2. config.json

{
  "schemaVersion": 1,
  "site": "https://company.atlassian.net",
  "email": "user@company.com",
  "spaceKey": "DEV",
  "spaceId": "98765",
  "homePageId": "123400000",
  "rootPageId": null,
  "options": {
    "attachments": true,
    "concurrency": 4,
    "maxFileNameLength": 80
  }
}
필드타입필수설명
schemaVersionintO파일 형식 버전. 형식이 바뀌면 올리고 마이그레이션한다.
sitestringOConfluence 사이트 주소
emailstringOkeyring 조회용 사용자 이름
spaceKey · spaceIdstringO대상 스페이스
homePageIdstringO스페이스 홈 페이지. 최상위 _index.md에 대응
rootPageIdstring | null--root로 받은 경우 그 페이지 ID
options.attachmentsbool첨부파일 받기 여부 (기본 false)
options.concurrencyint동시 요청 수 (기본 4, 최대 8)
options.maxFileNameLengthint파일명 최대 길이 (기본 80자)

3. index.json

페이지 ID를 키로, 마지막 동기화 시점의 상태를 기록한다. status 판정과 push 버전 비교의 기준이다.

{
  "schemaVersion": 1,
  "lastSync": "2026-11-10T09:30:00+09:00",
  "pages": {
    "123456789": {
      "path": "개발환경/Java-설치.md",
      "title": "Java 설치",
      "parentId": "123450000",
      "version": 14,
      "baseHash": "sha256:9f2c...e1",
      "remoteUpdatedAt": "2026-11-03T02:10:00.000Z",
      "attachments": ["설치화면.png"]
    }
  }
}
필드타입설명
pages.<id>.pathstring작업 폴더 기준 상대 경로, 구분자 /
titlestring마지막 동기화 시점 제목
parentIdstring | null마지막 동기화 시점 부모 페이지
versionint마지막으로 받거나 올린 웹 버전. push 충돌 판단 기준
baseHashstring마지막 동기화 시점 파일 내용의 SHA-256. 수정 여부 판단 기준
remoteUpdatedAtstring웹 마지막 수정 시각 (참고용)
attachmentsstring[]받은 첨부파일 이름

baseHash 계산: 파일 전체(front matter 포함)를 UTF-8, 줄 끝 LF로 정규화한 뒤 SHA-256을 구한다. 줄 끝 정규화로 Windows의 CRLF 변환 때문에 "바뀐 것처럼" 보이는 일을 막는다.

4. 페이지 파일 (.md)

4.1 front matter

---
id: "123456789"
title: Java 설치
version: 14
labels: [java, 개발환경]
---
필드타입필수편집설명
idstring기존 페이지금지Confluence 페이지 ID. 없으면 새 페이지
titlestringO가능페이지 제목. 바꾸면 웹 제목도 바뀜
versionint금지참고용 표시. 실제 판단은 index.json 기준
labelsstring[]가능페이지 라벨 (P2 범위)

id는 숫자지만 문자열로 저장한다. YAML이 긴 숫자를 다른 형태로 바꾸는 것을 막기 위해서다.

4.2 경로 규칙

  1. 하위 페이지가 없는 페이지: <부모 폴더>/<파일명>.md
  2. 하위 페이지가 있는 페이지: <부모 폴더>/<파일명>/_index.md
  3. 스페이스 홈(또는 --root 페이지): 작업 폴더 최상위 _index.md
  4. 파일명 만들기: 제목에서 Windows 금지 문자 \ / : * ? " < > |를 -로, 공백을 -로 바꾸고, 앞뒤 마침표 · 공백을 지운다.
  5. 파일명이 maxFileNameLength를 넘으면 자르고 끝에 ~<id 끝 6자리>를 붙인다.
  6. Windows 예약 이름(CON, PRN, AUX, NUL, COM1~, LPT1~)이면 끝에 _를 붙인다.
  7. 대소문자만 다른 이름이 겹치면 뒤에 오는 페이지에 ~<id 끝 6자리>를 붙인다(Windows는 대소문자를 구분하지 않음).

웹 제목이 바뀌면 pull 때 파일도 새 이름으로 옮긴다(git에는 이름 변경으로 기록됨).

4.3 매크로 보존 블록

```confluence-storage
<ac:structured-macro ac:name="info">
  <ac:rich-text-body><p>사내망에서만 접속됩니다.</p></ac:rich-text-body>
</ac:structured-macro>
```
  • 코드 블록 언어 표시가 confluence-storage인 블록은 Storage XML 원본이다.
  • 업로드 시 내용을 그대로 본문에 넣는다. XML로 파싱되지 않으면 그 페이지 업로드를 중단한다.
  • ac:macro-id 등 웹이 붙인 속성도 그대로 보존한다.
